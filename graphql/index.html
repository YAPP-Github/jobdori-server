GraphQL API Reference

GraphQL API 사용에 필요한 공통 규칙, 응답 모델, Query별 예제를 제공합니다.

1. Overview

1.1. Endpoints

GraphQL API

1.2. 공통 헤더 정보

GraphQL API도 REST API와 동일하게 HTTP Header로 인증 정보를 전달합니다.

Header Description Mandatory Example

Authorization

인증 토큰 (액세스 토큰)

인증이 필요한 Query는 Y

Bearer 4B561A51-7773-4CA4-8E67-851EF4E85145

Request-Id

요청 식별 ID

N

c64af254-d067-475c-b4ce-15a6f0a73f99

Authorization 헤더 값은 Bearer {accessToken} 형식입니다.

인증이 필요한 GraphQL Query에서 Authorization 헤더가 없거나 유효하지 않으면 인증 오류가 발생합니다.

1.2.1. 설정 방법

GraphiQL에서 인증이 필요한 Query를 테스트할 때는 Headers 영역에 다음 JSON을 입력합니다.

{
  "Authorization": "Bearer 4B561A51-7773-4CA4-8E67-851EF4E85145",
  "Request-Id": "c64af254-d067-475c-b4ce-15a6f0a73f99"
}

1.3. GraphQL 응답 모델

GraphQL 응답은 성공 시 data 필드를 포함합니다.

Path Type Mandatory Description

data

Object

Y

Query 실행 결과
Success Example
{
  "data": {
    "myUser": {
      "userId": "1",
      "name": "홍길동",
      "profileImageUrl": null
    }
  }
}

GraphQL 요청이 실패하면 errors 필드에 오류 정보가 포함됩니다. 클라이언트는 errors[].extensions.code 값을 기준으로 오류를 분기합니다.

Path Type Mandatory Description

errors

Array<Object>

Y

GraphQL 오류 목록

errors[].message

String

Y

오류 메시지

errors[].path

Array<String>

N

오류가 발생한 GraphQL field path

errors[].extensions.code

String

Y

애플리케이션 에러 코드

errors[].extensions.details

Array<Object>

N

필드별 상세 오류 목록

errors[].extensions.details[].field

String

Y

필드명

errors[].extensions.details[].reason

String

Y

오류 설명

data

Object

N

부분 성공 데이터. 전체 실패 시 null
Unauthorized
{
  "errors": [
    {
      "message": "인증이 필요합니다.",
      "path": ["experiences"],
      "extensions": {
        "code": "invalid_auth_token",
        "classification": "UNAUTHORIZED"
      }
    }
  ],
  "data": null
}
Invalid Arguments
{
  "errors": [
    {
      "message": "요청 값이 올바르지 않습니다.",
      "path": ["experiences"],
      "extensions": {
        "code": "invalid_arguments",
        "details": [
          {
            "field": "size",
            "reason": "1 이상이어야 합니다."
          }
        ],
        "classification": "BAD_REQUEST"
      }
    }
  ],
  "data": null
}
GraphQL 응답은 일부 오류 상황에서도 HTTP status가 200으로 내려갈 수 있습니다. 클라이언트는 HTTP status만 보지 말고 `errors[].extensions.code`를 기준으로 처리해야 합니다.

1.4. 공통 에러 코드

모든 GraphQL Query에서 공통적으로 발생할 수 있는 에러 코드입니다.
각 Query별로 발생할 수 있는 에러 정보는 각 Query의 에러 코드 문서를 참고해주세요.

Code GraphQL Classification Description

invalid_arguments

BAD_REQUEST

필수 파라미터가 없거나 파라미터가 유효하지 않은 경우

invalid_auth_token

UNAUTHORIZED

인증 토큰이 없거나 유효하지 않은 경우

token_expired

UNAUTHORIZED

인증 토큰이 만료된 경우

internal_error

INTERNAL_ERROR

서버 내부 오류가 발생한 경우

service_unavailable

INTERNAL_ERROR

현재 서비스를 이용할 수 없는 경우

2. Queries

2.1. 요청 예시

GraphiQL에서는 아래 GraphQL 문서를 그대로 입력해서 실행할 수 있습니다.

사용자 조회:

query MyUser {
  myUser {
    userId
    name
    profileImageUrl
  }
}

경험 목록 조회:

query Experiences($workspaceId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    experiences {
      id
      title
      tags
      project {
        id
        name
        role
      }
    }
    hasNext
    nextCursor
  }
}

Variables:

{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "cursor": null,
  "size": 20
}

프로젝트별 경험 목록 조회:

query ProjectExperiences($workspaceId: ID!, $projectId: ID!, $cursor: String, $size: Int!) {
  projectExperiences(workspaceId: $workspaceId, projectId: $projectId, cursor: $cursor, size: $size) {
    experiences {
      id
      title
      tags
      displayOrder
    }
    hasNext
    nextCursor
  }
}

Variables:

{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "projectId": 3,
  "cursor": null,
  "size": 20
}

경험 프로젝트 목록 조회:

query ExperienceProjects($workspaceId: ID!, $cursor: String, $size: Int!) {
  experienceProjects(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    projects {
      id
      name
      summary
      role
      period {
        startAt
        endAt
      }
    }
    hasNext
    nextCursor
  }
}

Variables:

{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "cursor": null,
  "size": 20
}

2.2. 필드 선택

GraphQL은 클라이언트가 필요한 필드만 선택해서 조회합니다.

예를 들어 경험 목록에서 프로젝트 정보가 필요 없으면 project 필드를 요청하지 않습니다.

query Experiences($workspaceId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    experiences {
      id
      title
      tags
    }
    hasNext
    nextCursor
  }
}

프로젝트 정보가 필요한 화면에서는 project 필드를 함께 요청합니다.

query Experiences($workspaceId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    experiences {
      id
      title
      project {
        id
        name
      }
    }
    hasNext
    nextCursor
  }
}

경험이 프로젝트에 연결되어 있지 않으면 `project`는 `null`입니다.

2.3. 커서 페이징

목록 Query는 cursor, size 파라미터를 사용합니다.

Parameter Type Description

cursor

String

다음 페이지 조회를 위한 커서입니다. 첫 페이지는 `null`로 요청합니다.

size

Int

한 번에 조회할 개수입니다.

응답의 hasNext`가 `true`이면 `nextCursor 값을 다음 요청의 `cursor`로 전달합니다.

query Experiences($workspaceId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    experiences {
      id
      title
    }
    hasNext
    nextCursor
  }
}

첫 페이지 Variables:

{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "cursor": null,
  "size": 20
}

다음 페이지 Variables:

{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "cursor": "5",
  "size": 20
}

3. 도메인별 에러 코드

현재 GraphQL Query에서 도메인 로직에 따라 발생할 수 있는 에러 코드입니다.

3.1. User

Code GraphQL Classification Description

user_not_found

NOT_FOUND

인증된 사용자 정보를 찾을 수 없는 경우

3.2. Workspace

Code GraphQL Classification Description

workspace_access_denied

FORBIDDEN

워크스페이스 접근 권한이 없는 경우

workspace_not_found

NOT_FOUND

워크스페이스를 찾을 수 없는 경우

Code GraphQL Classification Description
