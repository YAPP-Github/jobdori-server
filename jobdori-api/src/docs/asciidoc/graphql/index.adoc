== Queries

=== 요청 예시

GraphiQL에서는 아래 GraphQL 문서를 그대로 입력해서 실행할 수 있습니다.

사용자 조회:

[source,graphql]
----
query MyUser {
  myUser {
    userId
    email
    name
    profileImageUrl
  }
}
----

경험 목록 조회:

[source,graphql]
----
query Experiences($workspaceId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    experiences {
      experienceId
      title
      tags
      contents {
        type
        star {
          situation
          task
          action
          result
        }
        free {
          content
        }
      }
      project {
        projectId
        name
        role
      }
    }
    cursor {
      hasNext
      nextCursor
    }
  }
}
----

Variables:

[source,json]
----
{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "cursor": null,
  "size": 20
}
----

프로젝트별 경험 목록 조회:

[source,graphql]
----
query ProjectExperiences($workspaceId: ID!, $projectId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, projectId: $projectId, cursor: $cursor, size: $size) {
    experiences {
      experienceId
      title
      tags
      contents {
        type
        star {
          situation
          task
          action
          result
        }
        free {
          content
        }
      }
    }
    cursor {
      hasNext
      nextCursor
    }
  }
}
----

Variables:

[source,json]
----
{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "projectId": 3,
  "cursor": null,
  "size": 20
}
----

경험 프로젝트 목록 조회:

[source,graphql]
----

=== 필드 선택

GraphQL은 클라이언트가 필요한 필드만 선택해서 조회합니다.

예를 들어 경험 목록에서 프로젝트 정보가 필요 없으면 `project` 필드를 요청하지 않습니다.

[source,graphql]
----
query Experiences($workspaceId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    experiences {
      experienceId
      title
      tags
    }
    cursor {
      hasNext
      nextCursor
    }
  }
}
----

프로젝트 정보가 필요한 화면에서는 `project` 필드를 함께 요청합니다.

[source,graphql]
----
query Experiences($workspaceId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    experiences {
      experienceId
      title
      project {
        projectId
        name
      }
    }
    cursor {
      hasNext
      nextCursor
    }
  }
}
----

경험이 프로젝트에 연결되어 있지 않으면 `project`는 `null`입니다.

=== 커서 페이징

목록 Query는 `cursor`, `size` 파라미터를 사용합니다.

[.api-table]
[cols="20%,20%,60%",options="header"]
|===
| Parameter | Type | Description

| cursor
| String
| 다음 페이지 조회를 위한 커서입니다. 첫 페이지는 `null`로 요청합니다.

| size
| Int
| 한 번에 조회할 개수입니다.
|===

응답의 `+cursor.hasNext+`가 `+true+`이면 `+cursor.nextCursor+` 값을 다음 요청의 `+cursor+`로 전달합니다.

[source,graphql]
----
query Experiences($workspaceId: ID!, $cursor: String, $size: Int!) {
  experiences(workspaceId: $workspaceId, cursor: $cursor, size: $size) {
    experiences {
      experienceId
      title
    }
    cursor {
      hasNext
      nextCursor
    }
  }
}
----

첫 페이지 Variables:

[source,json]
----
{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "cursor": null,
  "size": 20
}
----

다음 페이지 Variables:

[source,json]
----
{
  "workspaceId": "8f13f49e-132a-47b7-b704-d7eec18fd44b",
  "cursor": "5",
  "size": 20
}
----
