==== API 응답 모델

====== Success

[.api-table]
[cols="30%,15%,13%,42%",options="header"]
|====
| Path | Type | Mandatory | Description

| `ok`
| Boolean
| Y
| 성공(true), 실패(false)

| `result`
| Object
| N
| API 결과
|====

[.example-panel]
======
.Success Example
[source,http]
----
HTTP/1.1 200 OK
Content-Type: application/json

{
  "ok": true,
  "result": {
    "key": "value"
  }
}
----
======

====== Error

[.api-table]
[cols="40%,15%,13%,42%",options="header"]
|====
| Path | Type | Mandatory | Description

| `ok`
| Boolean
| Y
| 성공(true), 실패(false)

| `error`
| Object
| Y
| 에러 정보

| `error.code`
| String
| Y
| 에러 코드 (에러 코드 문서 참고)

| `error.message`
| String
| Y
| 사용자에게 노출 가능한 에러 메시지

| `error.details`
| Array<Object>
| N
| 에러 상세 목록 (디버그용)

| `error.details[].field`
| String
| Y
| 필드명

| `error.details[].reason`
| String
| Y
| 에러 설명
|====

[.example-grid]
--
[.example-panel]
======
.Internal Server Error
[source,http]
----
HTTP/1.1 500 Internal Server Error
Content-Type: application/json

{
  "ok": false,
  "error": {
    "code": "internal_error",
    "message": "일시적인 오류가 생겼어요. 잠시 후 다시 시도해 주세요."
  }
}
----
======

[.example-panel]
======
.Invalid Arguments
[source,http]
----
HTTP/1.1 400 Bad Request
Content-Type: application/json

{
  "ok": false,
  "error": {
    "code": "invalid_arguments",
    "message": "입력한 내용을 다시 확인해 주세요.",
    "details": [
      {
        "field": "title",
        "reason": "Title must not be blank"
      },
      {
        "field": "content",
        "reason": "Content size must be between 0 and 500"
      }
    ]
  }
}
----
======
