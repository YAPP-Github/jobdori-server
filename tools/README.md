# Tools

## Google OAuth Code Test Tool 실행

```bash
python3 -m http.server 3000 -d tools
```

```text
http://localhost:3000/google-oauth-code-test-tool.html
```

## Notion OAuth Test Tool 실행

```bash
python3 -m http.server 3000 -d tools
```

```text

```
